# Windows

Windows 10 22H2(빌드 19045) 이상 및 Windows 11 x64용 STTS 설치 및 사용 안내.

## 설치

실행 파일은 Steam으로 배포할 예정이며, GitHub에는 소스 코드만 공개합니다. Steam 출시 전에는 다음과 같이 직접 빌드해 설치할 수 있습니다.

1. [소스 빌드](../docs/build.md)로 `dist/`에 설치 파일을 생성합니다.
2. 실행 중인 STTS를 트레이 메뉴에서 종료한 뒤 설치 파일을 실행합니다.
3. 관리자 승인을 허용합니다. VB-CABLE을 처음 설치했다면 PC를 재시작합니다.
4. 설치 후 열린 STTS에서 **처음 설정** 안내를 읽고 **사용 시작**을 누릅니다. 기본 설정에서는 창을 닫아도 트레이에 남으며, 트레이의 **STTS 열기**로 다시 열 수 있습니다.

Python, pip, CUDA Toolkit을 별도로 설치할 필요가 없습니다. GPU 사용에는 해당 GPU 드라이버가 필요합니다. STTS 설치 파일은 코드 서명되지 않았으며 Windows 보안 경고가 표시될 수 있습니다.

## Discord 연결

- 입력 장치: **STTS (VB-Audio Virtual Cable)**
- 출력 장치: 평소 사용하는 헤드폰·스피커

설치 시 가상 마이크 이름을 `STTS`로 지정합니다. Windows는 뒤에 `(VB-Audio Virtual Cable)`을 표시합니다. 이전 이름이 보이면 Discord를 다시 실행하세요. STTS 제거 시 직접 바꾸지 않은 마이크 이름은 설치 전 이름으로 복구됩니다.

가상 케이블을 처음 설치할 때 기존 기본 입력·출력과 기본 통화 장치를 보존합니다. Discord에서 STTS 입력을 선택해도 컴퓨터 전체의 기본 장치를 바꿀 필요는 없습니다.

연결에 문제가 있으면 **설정 → 가상 마이크 연결 점검**에서 음소거·0% 음량을 확인합니다. **케이블 음량 복구**는 가상 케이블 음량을 복구합니다.

마이크 접근이 차단되면 같은 화면의 **마이크 권한**에서 Windows 마이크 액세스와 데스크톱 앱 액세스를 허용합니다.

## 단축키

| 기본 단축키 | 기능 |
| --- | --- |
| Ctrl+Alt+Space | TTS 입력창 |
| Ctrl+Alt+S | STT 켜기·끄기 |

설정에서 단축키를 변경할 수 있습니다. TTS를 끄면 STTS의 생성·재생은 멈추며 공유 VB-CABLE 드라이버는 유지됩니다.

## 모델·목소리

첫 사용 시 필요한 모델을 자동으로 다운로드합니다. 중단된 다운로드는 완료한 부분부터 이어받습니다. [모델 목록](../docs/models.md)

하단 **보이스 클론**에서 3~30초 음성을 가져오거나 녹음해 등록합니다. 대본은 자동 입력하거나 직접 수정할 수 있습니다. 등록한 목소리는 TTS 중간·높음에서 선택할 수 있습니다.

데이터 위치: `%LOCALAPPDATA%\STTS`. 업데이트 시 설정·목소리·모델은 보존됩니다. 이전 모델은 **모델 관리**에서 삭제할 수 있습니다.

## 업데이트·제거

Steam판 업데이트는 Steam에서 관리할 예정입니다. 직접 빌드한 앱은 최신 소스로 다시 빌드해 설치합니다.

Windows 앱 설정에서 STTS를 제거합니다. 공유 VB-CABLE 드라이버와 개인 데이터는 보존됩니다. VB-CABLE 제거는 설치 폴더의 원본 드라이버 설치 프로그램을 사용합니다.
