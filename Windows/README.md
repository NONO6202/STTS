# Windows

Windows 11 x64용 STTS 설치 및 사용 안내.

## 설치

1. [릴리스](https://github.com/NONO6202/STTS/releases/latest)에서 `STTS-0.1.0-setup-x64.exe`를 받습니다.
2. 실행 중인 STTS를 트레이 메뉴에서 종료한 뒤 설치 파일을 실행합니다.
3. 관리자 승인을 허용합니다. VB-CABLE을 처음 설치했다면 PC를 재시작합니다.
4. STTS의 **처음 설정** 안내를 따릅니다.

Python, pip, CUDA Toolkit을 별도로 설치할 필요가 없습니다. GPU 사용에는 해당 GPU 드라이버가 필요합니다. STTS 설치 파일은 코드 서명되지 않았으며 Windows 보안 경고가 표시될 수 있습니다.

## Discord 연결

- 입력 장치: **CABLE Output (VB-Audio Virtual Cable)**
- 출력 장치: 평소 사용하는 헤드폰·스피커

**처음 설정 · 연결 점검**에서 음소거·0% 음량을 확인합니다. **케이블 음량 복구**는 가상 케이블 음량을 복구합니다. **신호 테스트**는 케이블로 테스트음을 보내 수신을 확인하므로 통화 밖에서 실행합니다.

마이크 접근이 차단되면 같은 화면의 **마이크 권한**에서 Windows 마이크 액세스와 데스크톱 앱 액세스를 허용합니다.

## 단축키

| 기본 단축키 | 기능 |
| --- | --- |
| Ctrl+Alt+Space | TTS 입력창 |
| Ctrl+Alt+S | STT 켜기·끄기 |
| Ctrl+Alt+V | TTS 켜기·끄기 |

설정에서 단축키를 변경할 수 있습니다. TTS를 끄면 STTS의 생성·재생은 멈추며 공유 VB-CABLE 드라이버는 유지됩니다.

## 모델·목소리

첫 사용 시 필요한 모델을 다운로드하고 해시를 확인합니다. 중단된 다운로드는 완료한 부분부터 이어받습니다. [모델 목록](../docs/models.md)

보이스 클론은 설정에서 3~30초 음성을 가져오거나 녹음해 등록합니다. 대본을 비우면 Whisper small로 인식합니다. 등록한 목소리는 TTS 중간·높음에서 선택할 수 있습니다.

데이터 위치: `%LOCALAPPDATA%\STTS`. 업데이트 시 설정·목소리·모델은 보존됩니다. 이전 모델은 **모델 관리**에서 삭제할 수 있습니다.

## 업데이트·제거

상단 파란 버튼 또는 설정의 **업데이트 확인**을 누릅니다. 다운로드와 SHA-256 검증이 끝나면 같은 버튼으로 설치합니다.

Windows 앱 설정에서 STTS를 제거합니다. 공유 VB-CABLE 드라이버와 개인 데이터는 보존됩니다. VB-CABLE 제거는 설치 폴더의 원본 드라이버 설치 프로그램을 사용합니다.
